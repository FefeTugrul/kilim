# docs

Kütüphanenin arkasındaki araştırma ve görsel denetim malzemesi. Buradaki
hiçbir şey npm paketine girmez (`package.json` içindeki `files` alanı yalnızca
`dist` ve `CHANGELOG.md` yayınlar); bunlar depo okuyucuları için.

- **`yoresel-motif-arastirmasi.md`** — altı yörenin motif ve kompozisyon
  karakteristikleri üzerine kaynaklı araştırma. `src/yore.ts` içindeki
  ağırlıkların dayanağı bu rapordur; her iddianın yanında güven seviyesi ve
  künye var, doğrulanamayan noktalar açıkça "bulunamadı" diye işaretli.
- **`yore-kontak-baskisi.png`** — altı yöre × sekiz tohum kontak baskısı.
  Profillerin görsel olarak gerçekten ayrıştığını tek bakışta gösterir;
  profil ağırlıkları değiştirilirken karşılaştırma zemini olarak kullanılır.
